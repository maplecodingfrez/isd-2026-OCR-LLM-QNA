# OCR/DB เทียบกับเล่มหลักสูตรจริง (ตรวจด้วยตาจากรูปหน้าตารางแผนการศึกษา)

วิธีตรวจ: เปิดรูปใน `runs/<แผน>/data_input/` แล้วเทียบกับ `plan_item` ใน `runs/<แผน>/lab8b_output/curriculum.db` ของรอบหลัก
(ไม่ใช่รอบ `*_retry`) ทีละแถว เลขหน้าคือเลขที่พิมพ์บนหน้าเล่ม

ชนิดความผิดเพี้ยน (ใช้เป็นรหัสในตาราง):
- **WILD** แถว wildcard (`xxx` / `xxxxxxxx` / `9064xxxx`) ไม่ถูกเก็บเข้า DB — เป็นข้อจำกัดเชิงโครงสร้าง ไม่ใช่ OCR อ่านผิด
- **MISS** วิชาที่มีรหัสจริงในเล่มแต่หายจาก DB
- **NAME** ชื่อวิชาผิด/ว่าง (ชื่อ = รหัส)
- **TYPO** ตัวสะกดผิดเล็กน้อย
- **SHIFT** รหัส/ชื่อถูกจับคู่ผิดแถว

## สรุปรูปแบบความผิดเพี้ยน (ข้ามทุกแผน)

1. **WILD (ใหญ่ที่สุด):** ทั้ง 7 แผนไม่เก็บแถว wildcard (`xxx`, `xxxxxxxx`, `9064xxxx`, `06026xxx` ฯลฯ) — ปีที่ 3-4 ขาดหลายแถว และบางเทอมหายทั้งเทอม
   (BIT no-coop 4/2, DSBA no-coop 4/2) เป็นข้อจำกัดของ pipeline โดยตั้งใจ (ไม่ใช่ OCR อ่านผิด) แต่ทำให้ `plan_item` รวมหน่วยกิตต่ำกว่าหลักสูตรจริงทุกแผน
2. **GROUP (เฉพาะ IT):** กลุ่มวิชา "เลือก 1 กลุ่มจาก 3" (ปี 2/2 และ 3/1) ถูกเก็บเป็นวิชาแยกแถวทั้งหมด ไม่มีโครงสร้าง "เลือกหนึ่ง" ใน DB
   และ DB ที่ IT ให้ผลรวมหน่วยกิตต่อเทอมเกินเล่ม
3. **NAME:** ชื่อวิชาเป็นรหัสซ้ำ/ชื่อซ้ำกับแถวคู่ "หรือ" ใน 8 จุด — AIT `06046444`, BIT no-coop `96642033`, BIT coop `06036148`, DSBA coop `06026260`, IT (ทั้งสองแผน) `06016415` และ `06016425`
