## Shot 0 (0:00-1:15) Cold start: เปิดเครื่องใหม่แล้วรันระบบ
- ภาพ: จอ Desktop ที่ไม่มีโปรแกรมอื่นเปิดอยู่ (ไม่มีเทอร์มินัล ไม่มี Ollama ในถาดระบบ ไม่มี uvicorn)
  1. (0:00-0:10) เปิดโฟลเดอร์โปรเจกต์ แสดงโครงสร้างตาม README หัวข้อ "โครงสร้างโฟลเดอร์" แล้วเปิด PowerShell ที่โฟลเดอร์นี้
  2. (0:10-0:25) ข้อ 1 ของ README: พิมพ์ `ollama serve` ค้างไว้ในเทอร์มินัลแรก แล้วรอจนขึ้นบรรทัด `Listening on ...` (ข้อความตรงตัวขึ้นกับเวอร์ชัน Ollama ตรวจตอนซ้อม)
  3. (0:25-0:40) เปิดเทอร์มินัลที่สอง พิมพ์ `.venv\Scripts\Activate.ps1` ให้เห็นว่า prompt ขึ้น `(.venv)`
  4. (0:40-1:00) พิมพ์ `python -m uvicorn lab10_fastapi.curriculum_app.main:app --host 127.0.0.1 --port 8000` รอจนขึ้น `Application startup complete` (ถ้าโหลดนานให้ speed-up 4x และใส่ตัวนับเวลา)
  5. (1:00-1:15) เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8000/api/health` ให้เห็น `status: ok` แล้วไปที่ `http://127.0.0.1:8000/` ให้เห็นหน้าเลือกหลักสูตร
- พากย์: "วิดีโอนี้เริ่มจากเครื่องที่เพิ่งเปิดใหม่ ยังไม่มีโปรแกรมอะไรทำงานอยู่ ตามขั้นตอนในไฟล์ README ข้อ 1 ขั้นแรกเปิดเทอร์มินัลที่โฟลเดอร์โปรเจกต์ แล้วรัน ollama serve เพื่อเปิดตัวโมเดลภาษา ขั้นที่สองเปิดเทอร์มินัลใหม่ เปิดใช้งาน virtual environment ขั้นที่สามรัน uvicorn เพื่อเปิดเซิร์ฟเวอร์ FastAPI ที่พอร์ต 8000 รอจนขึ้นว่า Application startup complete แล้วตรวจที่ api health ต้องได้ status ok จากนั้นเปิดหน้าเว็บก็พร้อมใช้งาน"
- Caption: "Cold start: ollama serve -> activate venv -> uvicorn -> เปิด :8000"
- ถ้าติดตั้งยังไม่เสร็จบนเครื่องอัด ให้ทำข้อ 1.1 ใน README ก่อนอัด ไม่ต้องใส่ในคลิป (ใส่ข้อความ "ติดตั้งครั้งเดียวตาม README ข้อ 1.1" บนจอสั้นๆ พอ)
