## ทดลอง OCR ใหม่

เลือก PDF หน้า 16, 22, 24, 28, 148 รวม 78 วิชา ทดลองเต็มหน้าและแบ่งคอลัมน์ที่ 300/400 DPI
ภาพและ OCR ไม่ได้ใช้ text layer หรือแคตตาล็อกเป็น input

| วิธี หลังใช้ parser ที่แก้แล้ว | รหัสที่แปลงได้ | ทุกช่องตรงอ้างอิง |

| Tesseract แบ่งคอลัมน์ 300 DPI | 75/78 | 51/78 |
| Tesseract แบ่งคอลัมน์ 400 DPI | 75/78 | 50/78 |

การเพิ่ม DPI หรือแบ่งคอลัมน์แบบนี้ยังไม่ให้ผลดีพอ จึงไม่เลือกใช้แทน production
ตำแหน่งคอลัมน์เป็นค่าที่เลือกจากภาพ GE66 โดยเฉพาะ ไม่ใช่ตัวตรวจตารางทั่วไป
หน้า 148 มีคำอธิบายรายวิชาที่ซ้ำกับหน้าอื่น รายงานแยกรหัสนอก sample เพื่อไม่ทำให้คะแนนสูงเกินจริง

หน้า 18 ของ Typhoon เดิมมีชื่ออังกฤษเลื่อนไปแถวถัดไปและบางแถวรวมหลายวิชา
ทดลองใหม่โดยแบ่งภาพตามตำแหน่งรหัสที่ Tesseract อ่านจากภาพ เป็น 4 ช่วง สูงสุด 6 วิชาต่อช่วง
ใช้โมเดลเดิม `scb10x/typhoon-ocr1.5-3b:latest` ภาพ 300 DPI ย่อช่วงภาพเหลือด้านยาวไม่เกิน 1536 px
ช่วงแรกอ่านได้ 6 วิชา และทุกช่องตรงอ้างอิงทั้ง 6 วิชา ใช้ประมาณ 121 วินาที ไม่ชน output token limit

ยังไม่ถือว่าทดลองครบหน้า และไม่ดาวน์โหลดหรือแก้ไฟล์โมเดลในเครื่อง

## การตรวจสอบและการจัดเก็บ

- ชุดทดสอบวิชาเลือกเดิม 994 กรณี + regression รูปแบบ OCR ใหม่ 15 กรณี ผ่านทั้งหมด 1009 กรณี

- ไม่แทนที่แคตตาล็อก/ฐานข้อมูลเว็บ และไม่อ้างว่าข้อมูล OCR ถูกครบทั้ง 303 วิชา

- ตัวอย่างเป็นชุดพัฒนา ไม่ใช่ held-out benchmark และ engine สองตัวเห็นตรงกันอาจผิดเหมือนกันได้

## รันซ้ำ

ใช้ source ที่มี parser fix ของ `feature/lab11-frontend` ร่วมกับเครื่องมือใน `dev/tests`
ต้องมี PyMuPDF, Pillow, pytesseract และ native Tesseract พร้อมภาษา `tha+eng`
Typhoon ใช้ Ollama และโมเดลเดิมที่พร้อมใช้งานในเครื่อง ไม่มีการติดตั้งโมเดลอัตโนมัติ

```powershell
$env:GE66_SOURCE_ROOT = '<source checkout>'
python tests/test_ge_ocr_formats.py
python scripts/ge66_ocr_audit.py --root '<source checkout>' --archive '<original OCR archive>' --output '<local output directory>'
```

ถ้ามีภาพ/ผล OCR ที่สร้างไว้แล้ว ใช้ `--reuse` เพื่อวัด parser ใหม่โดยไม่ OCR ซ้ำ
หลังแก้ปัญหา Ollama สามารถรันต่อโดยใช้ output directory เดิมที่เก็บผลช่วงแรกไว้:

```powershell
python scripts/ge66_typhoon_crops.py --root '<source checkout>' --output '<local output directory for page 18>'
```

ผลเก็บ raw OCR, ภาพ, code TSV พร้อม confidence/ตำแหน่ง, แถวที่ปฏิเสธ,
ผลวัดก่อน–หลัง และรายการที่ engine/วิธีอ่านให้ข้อมูลขัดกัน เพื่อเปิดภาพตรวจทีละรหัส
ควรตรวจชื่อไทยและชื่ออังกฤษของแถวที่มีข้อขัดแย้งก่อนพิจารณาใช้ OCR แทนข้อมูลปัจจุบัน
