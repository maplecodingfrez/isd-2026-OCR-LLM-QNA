# ผลการแก้ไขและตรวจคำตอบ — 2026-10-08

แก้ข้อผิดพลาดที่พบจากการตรวจครั้งนี้ครบแล้ว:

- กรองหน่วยกิตและชั่วโมงพร้อมกัน โดยไม่ละเงื่อนไข
- แยกคำค้นที่ล้มเหลวออกจากคำค้นที่รันสำเร็จแต่ไม่มีข้อมูล
- เติมรหัสวิชาที่คำตอบตกหล่นจากผล SQL
- ตอบสิทธิ์ลงวิชาต่อเมื่อระบุว่าได้ F จากข้อมูลวิชาบังคับก่อนเดิม
- แยกการขอชื่อภาษาอังกฤษออกจากการถามหาวิชาภาษาอังกฤษ
- ค้นชื่ออังกฤษที่ขึ้นต้นตามแผนจาก v_plan โดยตรง
- แก้การแปลงชั่วโมงแล็บที่เคยซ้ำคำว่าชั่วโมง
- แสดงคำอธิบายวิธีค้นสำหรับการค้นหัวข้อ แทน SQL ที่ไม่ตรงกับผล
- ใช้พื้นหลังมืดแบบ layered charcoal ตามตัวอย่างที่เลือก

ผลตรวจสุดท้าย:

- ชุดทดสอบรวม 2,044 ผ่าน และ 4 ข้าม เพราะบางแผนไม่มีวิชาโครงงาน
- คำถามเดิม 44 ข้อจากทั้งเจ็ดแผน ไม่มี HTTP error หรือ SQL flag ที่ตรวจพบ
- ค่าหน่วยกิตจาก Gold ที่ตรวจ 14 ข้อตรงทั้งหมด
- ตรวจเฉพาะข้อผิดพลาดและคำถามควบคุมบนเว็บจริงอีก 12 ครั้ง ผ่านเงื่อนไขที่กำหนดทั้งหมด
- ใช้โมเดลในเครื่อง qwen3:4b สำหรับเส้นทางที่ยังต้องเรียกโมเดล
- SHA256 ของฐานข้อมูลหลักสูตรและไฟล์ Gold ที่ตรวจไม่เปลี่ยน
- ชุดทดสอบใช้ source ของสาขา feature/lab11-frontend ร่วมกับ tests จากสาขา dev/tests

ผลนี้ครอบคลุมคำถามที่ตรวจ ไม่ใช่การรับประกันคำถามอิสระทุกรูปแบบ การตรวจหน้าเว็บรอบนี้ตรวจผ่าน HTTP และไฟล์ที่เสิร์ฟ ไม่ได้ตรวจภาพในเบราว์เซอร์
